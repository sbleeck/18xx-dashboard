### The Vision
> **"The interface should disappear into the game."**

The Desktop Dashboard replaces fragmented tabs and text logs with an immutable, unified board view:
* **The Map** remains permanently anchored on the left.
* **The Status Matrix** unifies players, corporate charters, treasuries, and train rosters.
* **The Stock Market** remains visible in real time in the lower quadrant.
* **The Action Hub** acts as a sequential checklist for turns and auto-hides when inactive.

### Install the Browser Extension (Public Beta)
1. Download **[18xx-dashboard-v1.0.0.zip](https://github.com/sbleeck/18xx-dashboard/releases/tag/v1.0.0)** and unzip it.
2. In Google Chrome, navigate to `chrome://extensions/` and toggle **Developer mode** on (top-right).
3. Click **Load unpacked** (top-left) and select the unzipped `18xx-extension` folder.
4. Open [18xx.games](https://18xx.games) and select the **Dashboard** tab.

*(The official Chrome Web Store one-click release is currently pending review).*
