# Privacy Policy for 18xx.games Desktop Dashboard

**Last updated:** October 2026

The **18xx.games Desktop Dashboard** browser extension is committed to protecting user privacy.

### 1. Data Collection and Transmission
This extension does **not** collect, store, track, log, or transmit any personal data, browsing history, authentication details, game credentials, or analytics.

### 2. Host Permissions
The extension requests host permission strictly for `https://18xx.games/*`. This permission is used exclusively by Chrome's `declarativeNetRequest` engine to load the local dashboard view layer (`main.js`) while visiting the platform. The extension remains completely inactive on all other websites.

### 3. Third Parties
No data is sold, transferred, or shared with third parties.

### 4. Contact
If you have questions regarding this extension, contact Stefan Bleeck at `bleeck@gmail.com`.
